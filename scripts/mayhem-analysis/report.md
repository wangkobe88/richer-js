# PumpFun Mayhem Mode（混乱模式）影响分析报告

**实验**: 157a300c-43b3-4eb0-b332-b3d74039f919（回测实验）
**源实验**: cf3e5e1d-9931-45e5-bfa9-f9caf0a9f161（虚拟交易实验，10000 代币）
**日期**: 2026-05-25

---

## 一、背景

PumpFun 的 `create_v2` 指令支持 Mayhem Mode（混乱模式）。在 Mayhem 模式下，代币的价格增长可能是由 agent（机器人）耗光流动性制造的虚假繁荣，而非真实的买盘需求。

## 二、数据采集方法

- **代币分类**: 通过 GMGN API 的 `/v1/token/info` 接口，查询每个代币的 `launchpad_platform` 字段
  - `pump_mayhem` / `pump_mayhem_agent` → Mayhem 代币
  - 其他 → 普通代币
- **全量代币采样**: 从源实验 10000 个代币中随机采样 1000 个
- **交易代币**: 回测实验中有买卖记录的 1023 个代币（全量查询）
- **收益计算**: FIFO 配对买卖，以 SOL 计价

## 三、Mayhem 代币占比

### 3.1 全量代币（源实验 10000 个，采样 1000 个）

| 类别 | 数量 | 占比 |
|------|------|------|
| Mayhem 代币 | ~2720 | **27.2%** |
| 普通代币 | ~7280 | 72.8% |

### 3.2 交易代币（回测实验 1023 个有交易的代币）

| 类别 | 数量 | 占比 |
|------|------|------|
| Mayhem 代币 | 929 | **90.8%** |
| 普通代币 | 94 | 9.2% |

### 3.3 关键发现

**策略对 Mayhem 代币有极强的选择性偏差**：

- 全量中 Mayhem 占 27%，但进入交易的 Mayhem 占 91%
- Mayhem 代币被买入的概率约为普通代币的 **26 倍**（(91%/27%) / (9%/73%)）
- 说明策略的信号系统（如 earlyReturn、K线形态等）更容易被 Mayhem 代币触发

## 五、结论

### 5.1 核心问题

1. **策略对 Mayhem 代币有强偏好**：27% 的 Mayhem 代币贡献了 91% 的交易，说明策略信号容易被 Mayhem 代币的价格波动触发。

2. **Mayhem 的正收益是"虚假繁荣"**：
   - 中位收益 -10.92%，60% 的 Mayhem 代币亏损
   - 整体正收益完全由 5 个 1000%+ 的极端赢家拉动（贡献约 72 SOL）
   - 这些极端赢家可能正是 Mayhem agent 制造的虚假价格——如果能卖在高位就赚到

3. **排除 Mayhem 后转为亏损**：
   - 全部净利润 +259 SOL → 排除 Mayhem 后 -12 SOL
   - 普通代币本身也没有优势（中位 -16.59%，盈利率 24.3%）

### 5.2 建议

- **方案 A（过滤 Mayhem）**: 在买入前检查代币是否为 Mayhem 模式（WSS 解析 `is_mayhem_mode` 或 GMGN `launchpad_platform`），直接过滤掉。但这会失去当前实验的全部正收益来源。
- **方案 B（保留 Mayhem，优化卖出）**: 接受 Mayhem 代币的高波动特性，优化卖出时机——在 agent 还在拉升时尽早卖出，避免被耗尽流动性后的暴跌。
- **方案 C（分离统计）**: 将 Mayhem 和普通代币分开统计收益，独立评估两套策略的表现，避免混合统计掩盖问题。

## 六、技术实现

### 6.1 WSS 实时识别（已实现）

在 `src/collectors/pumpfun-ws-collector.js` 中，`decodePumpCreateInstruction` 已扩展为解析 `create_v2` 指令中的 `is_mayhem_mode` 字段：

```
create_v2 指令数据布局 (Anchor 序列化):
[8B discriminator] + [name: 4B len + string] + [symbol: 4B len + string]
+ [uri: 4B len + string] + [creator: 32B pubkey] + [is_mayhem_mode: 1B bool]
```

Token 对象新增 `is_mayhem_mode` 字段，日志同步输出。

### 6.2 GMGN API 识别

GMGN `/v1/token/info` 返回的 `launchpad_platform` 字段：
- `pump_mayhem` — Mayhem 代币
- `pump_mayhem_agent` — Mayhem Agent 代币
- `pump` — 普通 PumpFun 代币

### 6.3 相关文件

- `src/collectors/pumpfun-ws-collector.js` — WSS 收集器（已支持 mayhem 识别）
- `src/core/gmgn-api/token-api.js` — GMGN Token API（`getTokenInfo` 返回 `launchpad_platform`）
- `src/core/gmgn-api/base-api.js` — `TRENCHES_PLATFORMS` 中已包含 `pump_mayhem`

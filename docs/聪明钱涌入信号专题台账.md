## SI-5 在场腿二修（用户语义修正「连续入场=前者仍持仓时后者明知接盘」，2026-11-18）

**用户澄清**：「我所谓连续入场，是指一个已经买入了，另一个又买入。不是时间上接近，而是一个买了明知道接盘另一个也要上」——SI-2 原判据只验价格接力，未验前序实体的持仓状态；A 买了又清仓走了、B 后买只是时间先后，不构成信号。

**判据增补（在场腿）**：链尾实体首买时刻，全部前序链内实体净持仓（boughtTok−soldTok）≥ 首买 token 量 ×`inflowPresenceMinRatio`(0.05)——已清仓离场=链断。载体改造（commit 812221ee）：实体结构重构 wallet→entity 引用共享（镜像成员同实体，顺带修原版镜像成员后续买入误建第二实体的边缘缺陷）；写点①②双向喂入（买单=首建/累计持仓、卖单=实体成员扣减）；defer 乱序晚到卖未到=在场高估（回测正序无此问题）。单测 C2 段三断言（清仓 96% 链断/恰 5% 残值在场/非实体卖忽略）29/0。

**两口径对照**：
| 口径 | 研究抽样（重写版同引擎对比） | 引擎全量（回测） |
|---|---|---|
| 时间共现版（无在场腿） | 81 票 43% +2.53B | **bt-v151：151 票 39.07% +2.1607B** |
| 在场腿版（用户语义） | 59 票 47% +2.19B | **bt-v152：113 票 38.05% +1.3757B** |

- 研究抽样口径在场腿胜率 +4pp 事件更纯；**引擎全量口径胜率持平（38% vs 39%）、pnl −0.79B**——被筛掉的 38 票（前者已走）在引擎里净贡献 +0.79B。
- **意外发现（留档待验）**：「前者已清仓离场后的进场」反而是更肥的面——抛压已释放（换手完毕）vs 前者持仓=悬着的抛压，与 T142「砸破发→换手完毕的重启位」同族逻辑。
- **裁定（2026-11-18 用户）：先以时间共现版为最优**——`inflowPresenceMinRatio` 缺省 0=关=共现版 bit（commit 9f280768；显式 0.05 factorParams 可恢复在场腿口径，机制代码+双向喂入保留）；bt-v151 为最优口径基准，bt-v152 在场腿版留档对照臂。跨窗验证以共现版为准、在场腿作敏感性臂并跑。

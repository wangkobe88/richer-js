## 一、模块定位与入口

叙事模块回答一个问题：**「这个 meme 币背后有没有值得参与的叙事」**，输出三档评级（1=low 拦 / 2=mid / 3=high 过）+ 分类（`token_category`）+ GMGN 风险快照，供买腿条件消费。决策全部走 **Jev**（api.typesafe.ai，结构化 Choice/Score/Noul 三原语，无自由文本生成，一票一次 fan-out 调用秒级）——聚合、阈值、截断全部在代码侧（`jev-result-mapper`），LLM 只答题不打分。

三个入口，同一核心 `NarrativeAnalyzer.analyze()`：

| 入口 | 触发 | 语境 |
|---|---|---|
| **引擎直调**（主入口） | 买腿 fire / C84 叙事发起条件触发 / N3 预触发 | `NarrativeDirectCaller.getRating()`，30s `Promise.race` 超时，超时后台续跑落缓存，永不抛错 |
| **Worker 批处理** | `narrative_analysis_tasks` 表队列（web 创建/实验发现入队） | `npm run narrative-engine`（`src/narrative/engine/start.mjs`），并发 30 |
| **Web 手动** | /narrative-analyzer 页 | `src/web/routes/narrative.routes.js`（/analyze、/reanalyze、/tasks CRUD） |

关键语义：
- **token 级全局缓存**：结果按 `token_address` upsert 进 `token_narrative`，跨实验共享；失效 = 行删或 `updateIsValid(addr,false)`；历史窗口回测前须先失效（题集变更后旧缓存缺新题答案）。
- **时间基准 = token 创建时间**（`raw_api_data.created_at`，flap 回退 wss_events token_create），绝不用墙钟——重跑/回测/延迟分析幂等。
- **失败语义**：precheck 拦截 → low 落库；无语料 → low（fail-closed 不买）；Jev 失败/超时 → `unrated`（归一 9）。

## 三、端到端主链（`NarrativeAnalyzer.analyze()`）

`analyze(address, options)` 全程（NarrativeAnalyzer.mjs:192-971），options 关键开关：`ignoreCache` / `enrichSocialByGmgn`（直调语境 GMGN 补源）/ `rowCache`（回测预载）/ `skipIntermediateSave`（直调省一次中段 DB 往返）/ `invalidateAccountCorpus`（账号语料失效重取）。

```
1  缓存查询      rowCache 命中 → 免 DB；否则 findByAddress
2  缓存判定      is_valid && !ignoreCache && !(enrich && no_public_info 行穿透) → 命中返回
                命中路径补充：enrichSocialByGmgn 且行内无 gmgn_info → 补调 GMGN 回写（不重析）
3  token 元数据  fetchTokenData（flap 创建时间由 wss_events token_create 补全）
4  数据抓取      fetchAllDataViaClassifier（见 §四）→ 各平台 Info + classifiedUrls + gmgnRisk
5  superIP 检测  detectSuperIP（注册表命中 → state 注入认证行，C83 起无独立通道）
6  账号预判      isProjectCoin / detectIssuerSelfLaunch（纯同步，先算值供泳道分派）
7  三泳道并发    ①账号链 collectAllAccountsWithFullInfo（chainPullsAuthor 宽判决定 issuerCa 排前/排后）
                ②precheck performPreCheck（不消费链产物）
                ③issuerCa detectIssuerByCaTimeline（字面法失灵时拉作者时间线找 CA 宣告推）
                ＋④空语料搜索兜底（C77，默认关，条件并发）
8  搜索旁路      no_public_info ∧ 搜索证据达阈值 → preCheckResult=null 走 Jev（详见 §五）
9  分支判定      isPreCheckTriggered？
   ├─ 是：preCheckDataToSave=结果，llmResult=预设，不烧 LLM
   └─ 否：进入分析
      9a  vision 门（C72）：主推有图未挂 image_analysis → 1 题 Choice 判文字语料够不够
          sufficient≥0.6 → 跳过 vision（本票无图语义，偏拦 fail-safe）

      9c  hasAnyData 兜底：全空 → low（no_data fail-closed，也落 pre_check_result 载体防 rating=null 行固化）
      9d  shouldUseAccountCommunity（账号/社区/项目币/issuer 检出）？
          ├─ 是：analyzeAccountCommunityToken → prestage 4 题（P1.10）→ rating 或规则拒绝

11 落库          NarrativeRepository.save（upsert 全局行；token_category null 不写键保旧值；
                gmgn_info 拿到才写 ?? existing 保旧值）
12 返回          formatResult + llmAnalysis + gmgnRisk + tokenCategory + meta{fromCache, searchBypassed…}
```

### 泳道并发的一个精妙约束（值得记录）

三泳道值层互不消费，唯一强耦合在缓存层：账号链与 issuerCa 都会对同一推文作者调 `getAccountWithFullTweets`（无 inflight 去重、双 key：全量 userId 级 vs `:ca:` 专属）。解法 = `chainPullsAuthor` 宽判（FourMeme 主链 :460-462）：链会拉作者 → issuerCa 排链后吃全量 key 缓存 handoff；链不拉 → 立即发起并行。宁损失并行度，不双真拉。

### 搜索旁路三场景（C77，NarrativeAnalyzer.mjs:495-528）

- 达阈值 → `preCheckResult = null` 强制走 Jev（保留 low 形状会被 resolveFinalRating 遮蔽 + 每次直调穿透烧配额 + preload 排除，三重反证裁定必须置 null）
- 未达阈值 → ruleName 不动保 1800s 重试域，additive 记 `details.searchEvidence`
- 搜索失败 → 零触碰 = 关闭功能 bit-identical
- 证据挂 `raw_api_data.search_evidence`（与 lag 提取链结构性无交叠——lag 隔离红线）

## 八、引擎侧集成

### 8.1 直调（NarrativeDirectCaller.getRating）

- **永不抛错**：成功/超时/异常统一体现在返回值（`numericRating` ∈ {1,2,3,9}；9=未评级放行，由买条件表达式裁决）
- **30s race**：`Promise.race([analyze, timeout])`；被弃的底层分析后台跑完 upsert，下轮命中缓存
- **inflight 去重**：同 token 并发共享同一 promise；TTL 穿透走独立 `'!ttl'` 槽（穿透要强制重跑，join 到常规调用上等于没穿透）
- **账号型 TTL 穿透**（C70 参数化）：`accountFailTtl` 默认关；命中「账号型语料 ∧ rating=1 ∧ 行龄≥intervalMs ∧ 真跑数<maxAnalyses」→ 强制 `ignoreCache + invalidateAccountCorpus` 重析。**回测禁穿透**（历史行 analyzed_at 恒早于墙钟，开启=语料前视）
- **计费两处**：穿透发起即计（失败也烧了配额）；常规真跑完成补计；缓存命中不计
- **回测 opt-in 内存缓存**：只缓存终态 PASS（rating∈{2,3} 且非 precheck-fail 重试域）；rating=1 不缓存（由引擎拉黑承担）；9 不缓存（保留重试）
- 附带导出：`mapGmgnRiskFactors`（GMGN 八因子映射单点，virtual/live/backtest 三路共用）、`extractCorpusTs`（语料最新推文时间：主推/父推/第二推文取 **Math.max**——朴蛋案裁定，旧梗新盘不再误判预热盘）、`isAccountOnlySource`、`shouldBlockOnNarrative`

## 十、缓存与持久化架构

### 10.1 token_narrative（token 级全局缓存）

- `save()` upsert by token_address：显式列清单写入（不整行覆盖）+ `SAVE_RETURN_COLS` 回读瘦列（N7 dbSave 瘦身）；`{existing}` 非 null 跳 pre-select 往返

### 10.2 external_resource_cache 键族（跨进程，CachedFetcher 统一管）

| 键 | TTL | 失效路径 |
|---|---|---|

### 10.3 进程内缓存（两套，各自独立）

- **引擎侧**（NarrativeDirectCaller）：token→rating 内存 Map（PASS-only，:140-153）+ inflight join（含独立 `'!ttl'` 槽）+ per-token 真跑计数（TTL 穿透上限）；进程重启全丢、首 fire 经 DB 缓存重建

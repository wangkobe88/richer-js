## 1. 全链路概览

入口 `NarrativeAnalyzer.analyze(address, options)`（`src/narrative/analyzer/NarrativeAnalyzer.mjs`）。LLM 决策全部走 **Jev**（api.typesafe.ai，结构化三原语 Choice/Score/Noul，无文本生成，一次 fan-out 调用秒级）；聚合/阈值/截断全部在代码侧 mapper。

| # | 步骤 | 要点 |
|---|---|---|
| 1 | 缓存检查 | `rowCache`（回测预载）或 `token_narrative` 按 token_address 最新 is_valid 行；命中直接返回 |
| 2 | 代币数据 | `experiment_tokens` 择优取行；created_at 缺失回退 `wss_events` token_create → `tokenCreatedAtSec`（**全链时间基准=代币创建时间，绝不用墙钟**） |
| 3 | 数据抓取 | `extractAllUrls` → IPFS metadata 解包（网关竞速 + pump.fun 迁移直链 C106）∥ GMGN 补源（仅 `enrichSocialByGmgn`）→ 0-URL 早退 → URL 分类分桶 → 四桶并发抓取；**C79 corpusGate** 在 twitter 主语料等齐后判一次，sufficient≥0.6 则待抓段整段跳过 |
| 4 | 中段 save | 落 url_extraction_result/classified_urls 供前端轮询（直调 `skipIntermediateSave` 跳过） |
| 5 | superIP 检测 | `SUPER_IP_REGISTRY` 命中 → state 注入认证/反混淆事实行（C83 起不预评分，评分全归 Jev） |
| 6 | 同步预判 | `hasIndependentWebsite`（剔 AUTO_TOKEN_PAGE_DOMAINS 自动聚合页 C99）/ `isProjectCoin`（内容臂+URL 臂）/ `detectIssuerSelfLaunch`（品牌同一性+宣告指纹） |
| 7 | 三泳道+搜索泳道并发 | ① 账号链 ② precheck ③ issuerCa（CA 时间线实锤）④ searchFallback（空语料时 C77） |
| 8 | 搜索旁路判定 | `no_public_info` + 双达标（去重剔转推≥3 且单推赞+2×转≥200）→ `pre_check_result` 置 **null** 强制走 Jev；未达保 1800s 重试域 |
| 9 | 分叉 | `isPreCheckTriggered` → 预设结果路径；否则 ① **C72 visionGate G1.2**（主推有首图且未挂 image_analysis 时 1 题预判：文本已把叙事陈述清楚才 sufficient≥0.6 跳过整段 vision；裸口号/官方措辞无上下文→need_image 走图片流程；已讲清热点 meme 的附视频/截图只是佐证不判 need_image）② 图分析 ③ **prestage 分叉**：账号/社区 token 或自发宣告或 isProjectCoin+relatedAccounts 或 issuerDetected → prestage 3 题；否则 **标准路径 Jev 19 题** |
| 10 | W 免费托管阻断 | 代码端规则：W 类 pass + 主站命中 FREE_HOSTING_DOMAINS → 覆写 low |
| 11 | 失败 fallback | 分析失败且有缓存 → 返回缓存（fromFallback） |
| 12 | 落库 | 四阶段信封 + `deriveTokenCategory` + `deriveSuperIpLabels` + upsert（null 列必须 `__clear`） |

**落库四信封与优先级**：`resolveFinalRating` 按 **pcr → prest → s1 → s2 → s3 → fin** 取第一个终态（早信封终态遮蔽晚信封）；score/reason 链则 fin 优先。`prompt_version` 形如 `jev-J1.55` / `jev-P1.13`，`prompt_type` 形如 `jev(J1.55/W类-W数学)`。

**URL 分类桶**（url-classifier）：twitter（tweet/account/community）、weibo、youtube、tiktok、douyin、bilibili、instagram、xiaohongshu、weixin、github、amazon、telegram、discord、binanceSquare、websites；图片 URL / DEX 链接直接丢弃。

**state 结构**（jev-state-builder，60k 预算）：头部 `[TOKEN][TIME]` + `[PRECOMPUTED]`（tweet_type、superIP 事实行）+ `[TWITTER_SEARCH]` 独立段（C77，不占四区配额、lag 隔离）+ 四区语料：twitter 40% / websiteGithub 25% / video 15% / others 20%（weibo/weixin/xiaohongshu/instagram/amazon/binanceSquare）。prestage state 20k 预算独立构造。

**当前生效开关**（`config/narrative-engine.json`）：`engine.maxConcurrency=30`、`jev.timeoutMs=30000/retryCount=2`、`vision.enabled=true` + `vision.gate{enabled:true,minSufficientProb:0.6}`、`corpusGate{enabled:true,minSufficientProb:0.6}`、`websiteFetch.enabled=false`（总开关关，t.co 展开保留）、`searchFallback.enabled=false`（默认关）、`precheckFailRetry.enabled=true`。

**引擎消费侧**（交易引擎，C84 模型）：`narrativeTriggerCondition`（FA 因子表达式）过门 → 后台 getRating → FA `narrativeRating`（null/1/2/3/9）→ 单一买条件裁决（`narrativeRating == 2 OR == 3`）；rating=1 且 accountOnly 可补轮重析（`narrativeRetry` 段：intervalMs/maxAnalyses/windowSec）。回测：rating 作为 token 常量注入（已知时序穿越，只看相对增量）。

### 2.2 expired_tweet 四桶分桶（C74）与主从结构门（C104）

**分桶器 `classifyTweetType`**（tweet-type-classifier.mjs），优先级从上到下：

| 桶 | 判据（满足即归此桶） | 时效处理 |
|---|---|---|
| `interpretive_reply` | 回复/引用/转发的目标在 SUPER_IP_REGISTRY 或高影响力名单 | 非豁免：载体集任一 lag≥300s 拦 |
| `angle_seeking` | 频繁发币者名单命中（C76 名单 147 号）；或粉<2000 且赞<100 且转<20 | 非豁免：同上 |
| `direct_tweet` | 粉≥5000，或 赞≥500，或 转≥100 | 豁免硬拦，交 Jev 软评 + **C104 主从门** |
| `unknown` | 中间地带/字段缺失兜底（followers 缺失不参与数值分桶） | 非豁免：同上 |

- 非豁免桶硬拦窗 `NON_EXEMPT_TWEET_FRESH_SEC = 300`：载体集（主推/website_tweet/quoted_status/retweeted_status）**任一** lag<300s 放行，否则拦。边界对齐买门 `narrativeCorpusLagSec < 300`。
- **C104 主从结构门**（direct_tweet 豁免桶）：主推 lag>24h 时，豁免须有主从结构——website_tweet/quoted/retweeted 任一 ≤24h（「实时传播正在发生」的新载体）；无新载体的裸旧推回落 300s 判定（此形必拦）。主推 created_at 缺失 fail-open 豁免照旧。

### 2.3 searchFallback（C77，默认关）

空语料票（twitterInfo null + 各桶全空）按 token 全名 + `since:<创建-7d>` 搜推特（Top/Latest 并发）。双达标（去重剔转推≥3 且单推赞+2×转≥200）→ **旁路 no_public_info**（pre_check_result 置 null 走 Jev）+ 证据挂 `raw_api_data.search_evidence`（★lag 隔离红线：narrativeCorpusLagSec 三路径结构性不读它）；未达阈值/失败不落缓存（保 1800s 重试域可翻案）。

### 2.4 PrecheckFailRetryService（两域重试）

| 域 | 判据 | 窗 | 重析参数 |
|---|---|---|---|
| `address` | 宣告竞态（validationStage='address'）+ **账号型语料形状门** + 增量 tick≥20 + ≤5 次 | 300s | `{ignoreCache, invalidateAccountCorpus:true}` |
| `no_public_info` | ruleName 命中 | 1800s | 先失效 GMGN 缓存，`{ignoreCache, enrichSocialByGmgn:true}` |

其余规则形状不在重试域。

## 3. Prestage 题集（P1.13，3 题）与定档逻辑

**触发分叉**：账号/社区 token（语料 URL 是账号页）或 `detectIssuerSelfLaunch` 自发宣告或 `isProjectCoin`+relatedAccounts 或 issuerCa 实锤 → prestage 路径（prompt_version=`jev-P1.13`）。

**规则前置验证**（纯代码 `performRulesValidation`）：addressVerified = CA 出现在账号 bio/置顶/官网（URL 含 CA 不算命中——C101）；nameMatch = 币名与账号名匹配。

### 3.1 三题

| 题 | 原语 | 桶值 | 判据要点 | 消费点 |
|---|---|---|---|---|
| `prestage_token_type` | Choice | `project` / `web3_native_ip_early` | 只看主叙事：功能性产品/服务/开发计划 = project；**币本身即 IP** = web3ip（a. 全新发明称号/概念「币安之王」型；b. 社区/文化 meme 主账号 MarsCoin 型——有官网/品牌也不算 project）。粉丝数不参与类型判断（只定档） | 仅 addressVerified=true 采信；web3ip + 推文语料不采信（C101 回落 abm） |
| `prestage_abm_name_link` | Choice | `exact` / `abbreviation` / `semantic` / `none` | 币名与账号名/简介/内容的最强关联——**按 web3 用户视角判**：只看币名，web3 用户会不会自然联想到该账号/人物（P1.13 用户感知锚；none=不会自然联想） | abm 条件一：≠none |
| `prestage_abm_web3_traffic` | Choice | `has_traffic` / `no_traffic` | 账号**自身** 30 天内真实 Web3 关注：被 KOL/机构主动提及、原发 crypto 内容高互动、与 Web3 大 IP 双向互动；自封合作/转发/单向 @ 不算 | abm 条件二：P(has_traffic)≥0.5 |

已删题：`prestage_project_quality`（P1.10 随账号基本面门全删）、`prestage_community_activity`（P1.12/C110 删——唯一消费方是社区臂 high 条件，删后社区臂回落恒 mid）。

### 3.2 定档逻辑（jev-prestage-mapper，纯代码）

```
addressVerified=false                  → account_based_meme：abm 双条件（名称关联≠none ∧ P(traffic)≥0.5）→ mid，否则 low
addressVerified=true ∧ web3ip ∧ 语料=tweet → 回落 abm 双条件（C101：web3ip 仅限账号语料）
addressVerified=true ∧ web3ip          → 账号基本面定档（rateProject：粉丝≥300→high 否则 mid）
addressVerified=true ∧ project         → 账号 0-299 粉 → mid；≥300 粉 → high；社区 → 恒 mid（P1.12）
```

- P1.10 后**无任何拦截**：粉丝/成员数只定档（baselineMet 恒 true），A 路径核心价值=CA 匹配。
- token_category 落库：prestage 路径 = tokenType（`project` / `account_based_meme` / `web3_native_ip_early`）。

## 4. 标准题集逐题详表（J1.45：16 基础 + 3 条件 = 19 题）

条件题挂载（`buildStandardQuestions(options)`，NarrativeAnalyzer 调用端）：
- `brand_hijack`：币名（去 emoji/数字）命中 `BRAND_HIJACK_KEYWORDS` 预检表（A 类头部币 BTC/ETH/PEPE…、B 类全球名人 CZ/elon/musk/trump…、C 类头部机构 binance/openai/google…）才问
- `name_image_consistency`：`!visionSkipped && twitterInfo.image_analysis` 存在（主推配图分析成功挂载）才问
- `parent_relationship`：`hasReplyParent(twitterInfo)`（任一载体槽位带【回复的推文】块）才问

无图不问、无父推不问——防幻觉作答，题集形状按语料分叉。

### 4.1 event_category（事件分类）— Choice 8 桶

| 桶 | 语义（判据要点） |
|---|---|
| **A** | 视觉 IP：meme 角色/吉祥物/虚拟形象/表情包角色。**代币名指向作品中角色 → 主体=该角色 → A 类**（J1.16 角色规则；作品官方宣传推只是角色语料载体） |
| **W** | 区块链/crypto 产品发布或更新（token/DeFi/NFT/公链/基础设施）。**D vs W 边界（J1.27）**：crypto 原生机构官号官宣**自家**新产品 → D；W 留给产品/项目本身为主体的独立发布 |
| **B** | 非 Web3 产品发布/更新。仅「独立新产品发布/重大升级」构成 B 类事件；版本更新/功能改进/平台移植 → E/D 阻断档 |
| **F** | 作者呈现**自己的发现**：隐藏模式/数据洞察/叙事关联（J1.37 澄清：目击/报道新闻≠发现——"spotted/noticed" 只是目击动作，那判 E） |
| **G** | 对未来事件的预测，有推理但证据不足 |
| **C** | 个人以个人身份发言（即使 CEO——除非作为机构官方喉舌） |
| **D** | 机构官方账号的公告/行为 |
| **E** | 正在平台传播的趋势/病毒内容（meme/挑战/热帖/热搜），推文只是报道或骑乘 |

主体归属规则：找角度推/解读回复 → 主体=被借势的原始事件；报道外部热点 → 主体=热点主角；作者自己的内容 → 主体=作者（粉丝数才代表量级）。

**消费点**：全部下游门/分的类别轴；`token_category = event:<X>`；cashtag→W（J1.17）与 F+news_recap→E（J1.37/C96）两处代码改道；A 类豁免 rcp 门（J1.16）。
**沿革**：J1.16（C25）/J1.27（C55）/J1.37（C96）。

### 4.2 finding_vs_recap（发现 vs 新闻转述）— Choice 3 桶

| 桶 | 判据 |
|---|---|
| `narrative_finding` | 作者声称发现/揭示隐藏模式/洞察/关联——被发现的东西此前不为人知，发现本身是卖点 |
| `news_recap` | 报道/目击/搬运/庆祝一条已发生的新闻——「发现语气」不构成发现，事件主体是外部实体 |
| `unclear` | 无法判断 |

**消费点**：`event_category=F ∧ choice=news_recap` → **强制改道 E**（`categoryForced='f_recap_e'`，E 类既有门自动接管——分类逃逸是过关钥匙）；非 F 类时纯观察落库。
**沿革**：J1.37 新增（C96 币安上电视案）。

### 4.3 web3_user_impact（Web3 用户被影响程度）— Score 6 档（E/D/C/B/A/S）（J1.54 由 event_magnitude 改名，判据不动）

**主体判定**（两形状，J1.20）：① 陈述者关联事件（事件=本人言行/作品）→ 主体=陈述者，按粉丝/知名度定档；② 陈述者只是转述 → 主体=外部事件本身，按传播规模定档，陈述者粉丝既不代表也不封顶。回复/转述按父推/源头定形状（十万粉级以上父推=大V扩散证据，计入）。

| 档 | 量表锚 | 分（MAGNITUDE_TIER_SCORES） |
|---|---|---|
| S | 世界级 IP/公司/颠覆性产品/顶级机构/全球热点（亿级传播） | 39 |
| A | 知名大 IP/知名公司/全国级人物或机构/全国级热点 | 34 |
| B | 知名 KOL（粉>4 万）/知名中小 IP/普通公司特色产品/平台级爆款（播放 100 万+） | 27 |
| C | 一般 KOL（粉<4 万）/社区级讨论；**主体无法追溯时最高到此档**（仅主体存在性封顶，J1.35） | 22 |
| D | 小主体（粉<1 万创作者/地区性小事） | 0（阻断） |
| E | 完全无热度/无价值（各类阻断档） | 0（阻断） |

类别特判：

### 4.16 web3_user_acceptability（Web3 用户接纳度）— Choice 3 档 = **唯一名字门**（J1.53 由 name_form 改名，判据不动）

仅就**链上 Symbol（币名/ticker）**本身判断：**web3 用户能不能接纳这个名字作为 meme 币的名字**——有没有感知、能否被记住、被抓住当符号玩梗。「是否合适作为 meme 币」是唯一判据；语言学分类只是佐证。链上 Name（全名/描述句）不是本门判据（C130 裁定，J1.69）。

题面四分支：

| 分支 | 判定 | 例 |
|---|---|---|
| ① 合格·指向实体 | 实体是**圈内符号/超级 IP/有玩味空间**——只确认「圈内用户认得它、接得住它」（实体量级另有题评） | CZ、PEPE、币安、狗狗币、暗号資産の覹者、货币自由、HODL、LFG |

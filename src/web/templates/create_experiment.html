📖 叙事分析

当因子满足比例达到此值时，触发叙事分析任务（0-100）
虚拟/实盘模式等待叙事分析完成的最长时间（秒）
轮询叙事分析结果的间隔时间（毫秒）
💡

说明

  • 独立引擎异步执行：叙事分析由独立引擎处理，不阻塞实验引擎主循环
  • 分阶段输出：Stage 1 完成时 narrativeRating=8（中间值），Stage 2 完成时返回最终评级 1/2/3
  • 轮询等待机制：实验引擎会轮询等待分析结果（虚拟/实盘默认10秒，回测5分钟）
  • 使用建议：使用条件 narrativeRating > 1 确保只购买已评级的代币，或 narrativeRating >= 2 只要评分完成就购买
  • 优先级：因子满足比例越高，任务优先级越高，优先被分析
  • 立即提交：勾选"发现新币立即提交"后，新代币在第一轮数据采集时立即提交叙事分析任务，不再依赖因子满足比例触发
  • 缓存复用：同一代币只分析一次，结果跨实验共享

🌡️ 行为周期判定（cycle 分桶路由）

实验级配置——本实验如何把代币分到冷/中/热行为桶（与库条目无关，复制实验各持口径）

tps30s ≥ 此值 → 热桶
tps30s ≥ 此值 → 至少中桶
tick 间隔中位数 ≤ 此值 → 热桶
间隔中位数 ≤ 此值 → 至少中桶
低于此值（已过热身期）→ 判冷桶 ❄️
代币年龄小于此值 → 档位 null
升档需持续此时长（追热要快）
降档需持续此时长（抗瞬抖）
无 tick 超此时长 → 立即降冷桶
间隔中位数取尾部此数个样本

档位判定 = tps30s（30s 滑窗 tick 密度）OR gapMedianMs（5min 窗间隔中位数）双主量； 不启用时带 groups 的腿全隐（fail-closed，止损双腿兜底）。改参数 = 改本实验分桶口径（与库条目无关）。

📖 条件表达式语法帮助（点击展开）

可用因子

因子 类型 说明 示例
age 数字 代币年龄（分钟） age < 1.33
earlyReturn 数字 早期收益率（%） earlyReturn >= 80
currentPrice 数字 当前价格 currentPrice > 0
collectionPrice 数字 收集时的基准价格 currentPrice > collectionPrice
highestPrice 数字 历史最高价格 currentPrice > highestPrice * 0.9
drawdownFromHighest 数字 距最高价跌幅（%） drawdownFromHighest <= -20
profitPercent 数字 盈利百分比（%） profitPercent >= 30
holdDuration 数字 持仓时长（秒） holdDuration > 60
txVolumeU24h 数字 24小时交易量（USD） txVolumeU24h > 50000
holders 数字 持有者数量 holders >= 100
tvl 数字 总锁仓量（USD） tvl > 10000
fdv 数字 完全稀释估值（USD） fdv < 100000
marketCap 数字 市值（USD） marketCap > 5000

操作符

  • AND: 且条件（两个条件都满足）
  • OR: 或条件（任一条件满足）
  • > >= < <= == !=: 比较运算符
  • ⚠️ 逻辑词只能写 AND/OR，不支持 &&/||/===：误写 && 或 || 不会报错，但其后的条件会被静默忽略（条件被截断）

组路由（groups，从库引用携带）

  • cycle 档位如何判定（冷/中/热的门槛与稳定性参数）由上方「🌡️ 行为周期判定」配置区决定——实验级配置，改参数=改本实验分桶口径（与库条目无关）
  • 腿可带 groups 表达式限定只对特定行为周期桶生效：cycle==3（热桶）/ cycle==2（中桶）/ cycle==1（冷桶），具体门槛（tps/间隔）见上方「🌡️ 行为周期判定」当前配置；支持 cycle!=3、cycle>=2、cycle==1 OR cycle==3 组合
  • 档位为 null（证据不足/热身期/实验未开周期路由）时该腿不可见（fail-closed，不评估不触发），无 groups 的腿恒可见
  • 「从库引用」展开的腿自动携带库内 groups、复制腿的 v1 cycle 数字按等价语义归组展示；快照语义——引用后本实验腿与库独立（腿在创建页只读，调整去策略库页），改库不影响已建实验（重启实验进程才生效新腿）
